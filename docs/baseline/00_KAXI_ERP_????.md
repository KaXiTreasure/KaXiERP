### 3.2 技术方向

当前工程采用的技术基线为：

```text
后端：Python 3.13 + Django 5.2 + Django REST Framework
数据库：PostgreSQL 17
异步任务：Celery + Redis
对象存储：MinIO / S3兼容存储
前端：React 19 + TypeScript + Vite
架构：模块化单体
```
